# Changelog

All notable changes to this package are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow SemVer.
Entries from 1.7.1 back were generated by semantic-release from commit subjects.

## [2.0.0] - 2026-09-21

Brings the wrapper up to the current BFL API (spec snapshot
`docs/openapi-snapshot-2026-09-20.json`). Twenty-one endpoints, video support,
and a CI check that fails the build when the live spec drifts from the wrapper.
Design rationale in `docs/DECISIONS.md`.

### Added

- **FLUX.2 [max]**, **[klein] 4B**, **[klein] 9B**: `generateFlux2Max`,
  `generateFlux2Klein4b`, `generateFlux2Klein9b`.
- **FLUX Tools (image)**: `deblurImage`, `eraseImage` (`dilate_pixels`),
  `outpaintImage` (canvas `width`/`height`, `reference_offset_x/y`, `auto_crop`,
  `mode`), `virtualTryOn` (`person`, `garment`).
- **FLUX 3 video**: `generateFlux3Video` (discriminated union on `mode`:
  `t2v` / `i2v` with `keyframes` / `v2v` with `start_video` / `draft_enhance`
  with `draft_cache`), `editVideo`, `upscaleVideo`. The CLI saves video as
  `.mp4` and defaults `--timeout` to 900 s for it.
- **FLUX 1.1 [pro] Ultra finetune**: `generateFluxProUltraFinetuned`.
- **Finetune utilities**: `getFinetuneDetails`, `deleteFinetune`
  (CLI `--finetune-details`, `--delete-finetune <id> --yes`).
- `user`, `webhook_url`, `webhook_secret` forwarded on every endpoint whose
  schema declares them (`CommonRequestFields`).
- `image_prompt` on FLUX.1 [dev]; `guidance`/`steps` on FLUX.2 [flex];
  `aspect_ratio`/`prompt_upsampling` on Kontext.
- `webp` accepted as `output_format` everywhere.
- `BflHttpError` (`status`, `retryAfter`) thrown for HTTP failures.
- `MODELS` registry (`path`, `label`, `media`, `defaultOutputFormat`),
  `MODEL_FIELDS`, `FLUX3_VIDEO_MODE_FIELDS`, `getModelInfo`,
  `ModelConstraint.fields` for 2.0-era parameters.
- `scripts/check-spec-drift.ts` (`npm run check:spec`, `check:spec:control`,
  `check:spec:snapshot`) and `npm run verify`; CI runs the control and the live
  check before the tests.
- `validateVideoPath`, `videoToBase64`, `downloadMedia`, `downloadVideo` in
  utils. CLI `--dry-run` elides base64 payloads.

### Changed

- **`generateFlux2Pro` no longer sends `prompt_upsampling`.** The API replaced
  it with `disable_pup` (upsampling on by default). `Flux2Params` is now the
  union of `Flux2ProParams` \| `Flux2FlexParams` \| `Flux2KleinParams`.
- **Kontext `input_image` is optional** (text-only generation); the wrapper
  used to throw without it.
- **Generation methods return `SubmitResult`** (`id`, `polling_url`, `cost`,
  `input_mp`, `output_mp`, or `status`/`webhook_url` in webhook mode) instead
  of `TaskResult`.
- **`TaskResult.status` is the full `TaskStatus` union** (`Task not found`,
  `Pending`, `Reasoning`, `Generating`, `Request Moderated`,
  `Content Moderated`, `Ready`, `Error`); gained `progress`, `details`,
  `preview`, `cost`. `waitForResult` continues through `Reasoning`/`Generating`,
  throws immediately on `Task not found`, treats `Request Moderated` as
  terminal (it was polled through before), reads the error from
  `details.error`, and honours `Retry-After` on transient polling errors.
- **Only fields the caller sets are sent**, so server defaults apply; the
  wrapper no longer forces `prompt_upsampling: true` on FLUX.2.
- **CLI file extension follows the server default** when `--output-format` is
  omitted — Kontext, deblur, erase and outpaint output is saved as `.png`
  (Kontext was PNG data named `.jpg` in 1.x). Output directory is per model key.
- CLI range validation now comes from `validateModelParams` (one table for CLI
  and library) instead of a parallel hand-written validator. Selecting two model
  flags is an error rather than first-wins.
- `MODEL_CONSTRAINTS` per-model `safetyTolerance` reflects the API: 0–6 FLUX.1,
  0–5 FLUX.2 / tools, 0–4 video.
- API-key help text points at `https://dashboard.bfl.ai/`.
- Releases are manual (`version` bump, this file, `npm run verify`,
  `npm publish`). semantic-release, its plugins, `.releaserc.json` and the
  release workflow are removed; `.github/workflows/ci.yml` verifies every push.

### Removed

- `Flux2Params.prompt_upsampling` for [pro]/[max] (see Changed).
- The Kontext `input_image is required` error.
- semantic-release and its six plugins from `devDependencies`.

### Fixed

- `Task not found` no longer polls until timeout.
- `webp` no longer rejected client-side while the server accepts it.
- 502/503 with `Retry-After` on the polling URL waits the requested interval
  instead of the fixed backoff.
- `getResult(id)` without a polling URL now explains the 404 the global host
  returns for a regionally-served task instead of echoing "HTTP 404". The CLI
  writes `polling_url` into every metadata file and `--get-result` takes
  `--polling-url` (found live: a task submitted via `api.bfl.ai` was served
  from `api.eu2.bfl.ai`).
